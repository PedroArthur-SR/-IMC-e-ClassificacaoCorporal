# 🧮 IMC e Classificação Corporal

Projeto desenvolvido em Java como exercício de **Programação Orientada a Objetos (POO)**.

## 📌 Sobre o projeto

O programa recebe os dados de uma pessoa através do teclado, calcula seu **Índice de Massa Corporal (IMC)** e informa sua classificação de acordo com a faixa de massa corporal.

## 🛠️ Tecnologias

* Java
* IntelliJ IDEA

## 📚 Conceitos praticados

* Classes e objetos
* Encapsulamento
* Atributos `private`
* Getters e setters
* Construtores
* Métodos
* Estruturas condicionais (`if`)

## ▶️ Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute a classe `Main`.
4. Informe os dados solicitados pelo programa.

## 📋 Funcionamento

O usuário informa:

* Nome
* Sobrenome
* Idade
* Altura
* Peso

A partir desses dados, o programa cria um objeto `Pessoa`, calcula seu IMC e informa sua classificação corporal.

### Fórmula

```text
IMC = peso / (altura × altura)
```
